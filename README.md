# Custom Gallery App

Custom Gallery is an Android app for browsing device photos and videos in a clean grid with quick preview and selection tools. It supports sharing, deletion, album navigation, and modern media permissions for smooth day-to-day gallery management.

## Features
- Grid view for photos and videos
- Full-screen media preview
- Multi-select media support
- Share selected media
- Delete selected media
- Swipe-left from Grid View to open Album View
- Android media permission handling
